## Description

One rented property can be used in more than one way. The author can run it as supported accommodation or as temporary accommodation. Having more than one exit is part of the value he brings to the table when he negotiates with a landlord.

## Details

- Exit 1: supported accommodation
- Exit 2: temporary accommodation
- The author counts these exits as part of his worth in a negotiation
