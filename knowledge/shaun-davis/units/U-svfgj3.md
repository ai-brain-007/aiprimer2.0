## Description

Rapport starts faster when you and the agent share something: a language, a background, a place. Shaun watches for it and uses it. When Sandu and an agent both spoke Romanian, they connected straight away and two properties were on the table within minutes.

## Details

- Look for common ground the moment you walk in: shared language, origin, area, anything real you both have.
- Use it to create synergy and connect before you talk business.
- Example: Sandu and the agent both spoke Romanian; the agent showed two three-bed properties at £1,500 and asked them to return in an hour when his brother, the lettings agent, was back.
- This sits inside the rapport recipe: build rapport, find common ground, keep it simple.
