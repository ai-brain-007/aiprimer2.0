## Description

Shaun's view is that the results are not a mystery. There is a formula that has worked time and time again; copy it, follow it step by step, and you get the same result. Do not reinvent the strategy.

## Details

1. Accept there is a proven formula that has been done time and time again.
2. Copy it.
3. Follow it step by step.
4. Expect the same result.
The flip side: if you are not making £5,000, £10,000 or £15,000 a month, there is a reason why.
