## Description

There are many terrible deal sourcers. If you cannot find and analyse a deal properly you will sell deals that do not stack up. Learn to analyse first, sell second.

## Details

- Mistake: passing deals to investors without checking that the numbers stack up.
- Consequence: you join the many terrible deal sourcers out there.
- Fix: learn how to find a deal and how to analyse it effectively. Only then sell it to the investor.
