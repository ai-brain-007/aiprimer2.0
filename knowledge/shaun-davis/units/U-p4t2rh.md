## Description

You get paid in proportion to the value you create and the problems you solve. People do not pay for things, they pay for value. So if you want more money, the job is to create more value, so that money chases you rather than you chasing it.

## Details

- Money follows value.
- Create more value and solve more problems, and you are compensated in proportion to the value and the problems solved.
- People do not pay for things; they pay for value.
- To make more money, create more value.
- The aim for the kids: create value in the marketplace so that money chases them, not the other way around.
