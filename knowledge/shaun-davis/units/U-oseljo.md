## Description

There is no single rulebook. Some councils find the tenants for you, others expect you to find them. Some place one family in a house, others want individual rooms in an HMO. Furnishing rules change too. You have to learn how each council you work with operates.

## Details

- Tenant sourcing: some councils find the tenants for you; with others you find the tenants yourself
- Occupancy: some councils place one family in a house; some run an HMO setup with individual rooms
- Furnishing: some councils require a full set of bedroom furniture; some only ask for a bed and expect the tenant to provide the rest
